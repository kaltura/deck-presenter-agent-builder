# Canopy integrations (fictional demo content)

Invented integration details for this demo's fictional product. None of this
describes a real product or a real partner.

## Valve controllers

Canopy's automation feature (slide 7) connects to a farm's existing valve
controllers through a standard control interface. No specific brand is named
in this demo; a real project would list the brands it actually supports here.

## Weather data

The moisture forecast on slide 5 combines sensor readings with a local
weather feed. In this fictional demo, the weather feed is described only as
"a local weather feed," not a named provider.

## Export

The dashboard can export a farm's moisture history as a spreadsheet for
record-keeping. This demo does not describe any other export format.
