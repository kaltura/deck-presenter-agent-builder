# Canopy FAQ (fictional demo content)

Everything in this file describes a fictional product, invented only for this
toolkit's demo project. No claim below describes a real company or product.

## Does Canopy replace our existing irrigation hardware?

No. Canopy connects to the valve controllers and sensors a farm already runs.
It adds monitoring and, optionally, automation on top of that hardware.

## What happens if a sensor loses power or signal?

The dashboard marks that field as "no data" instead of showing a stale
reading, so the team never acts on old information without knowing it.

## Can more than one person on the team get alerts?

Yes. Alerts can go to any number of phones on the team, not just one
account.

## Does Canopy work in the off season?

Sensors keep reporting year-round, so the team can watch soil conditions
even when nothing is planted, not just during an active growing season.

## Is there a mobile app?

The dashboard works in a phone browser. This demo does not describe a
dedicated mobile app.
